# Course outlines

Official SAIT PDFs live here. They are the source of truth for **what** to teach, not the wording.

The app never copies sentences, definitions, diagrams, assignments, or quiz questions from these files. Outlines tell us which topics belong in `src/content/courses.json`. Lessons, examples, and quizzes are written originally in plain language.
